# تطبيق المجلس — المرحلة الأولى

هذه الحزمة تحول BUILD 229 إلى بنية مشروع Capacitor جاهزة لاستكمال تطبيق iOS.

## ما تم إنجازه

- وضع اللعبة كاملة داخل `www/index.html`.
- إنشاء إعدادات التطبيق باسم «المجلس».
- اعتماد معرّف مبدئي: `com.almajlis.game`.
- تعطيل التمرير غير الضروري ومعاينة الروابط داخل iOS.
- إعداد أوامر مزامنة وفتح مشروع iOS.

## التشغيل على Windows

افتح PowerShell داخل هذا المجلد ثم نفّذ:

```powershell
npm install
npx cap add ios
npx cap sync ios
```

يمكن تجهيز ملفات iOS على Windows، أما البناء والتوقيع فسيتم لاحقًا عبر Codemagic أو على جهاز Mac باستخدام Xcode.

## المرحلة التالية

إعادة تصميم الهوية البصرية لتصبح «المجلس» لعبة مسابقات أصلية بمظهر تطبيق احترافي، ثم إنشاء الأيقونة وشاشة التشغيل وضبط الاتجاه الأفقي والعمودي قبل اختبار TestFlight.
